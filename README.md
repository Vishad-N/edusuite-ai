# EduSuite AI - All-in-One Desktop Studio for Schools & Coaching Institutes

EduSuite AI is a modern desktop software application designed for educational institutions, schools, tuition centers, and coaching academies (NEET/JEE, Commerce, K-12). It brings high-productivity AI tools under a single native desktop interface.

---

## 🌟 Core Features Included:

1. **📊 AI Presentation Maker (PPTX Generator)**:
   - Enter any academic topic (e.g. *Photosynthesis*, *Newton's Laws*, *Periodic Table*).
   - Generates visually formatted slides with concepts, exam tips, and speaker takeaways.
   - **Real `.pptx` Export**: Generates actual PowerPoint `.pptx` files compatible with Microsoft PowerPoint, Google Slides, and LibreOffice.

2. **🖼️ AI Image & Poster Studio**:
   - Coaching admission banners (*New Batches starting Monday*, *Super 30*).
   - Result celebration & Topper ranker creatives.
   - High-detail scientific diagrams prompter (Human Heart, Cell anatomy, Optics).
   - Multi-format aspect ratio support (1:1 Square for WhatsApp, 16:9 Landscape, 9:16 Story/Reels).

3. **📝 AI Question Paper & Quiz Maker**:
   - Blueprint configuration: MCQs, Short Answers, and Long Conceptual derivations.
   - Automatic Answer Key & Teacher Evaluation Guidelines.
   - One-click **Print / Save as PDF** and **Copy Clean Text for MS Word**.

4. **📢 Notice & WhatsApp Broadcast Hub**:
   - Parent broadcast alerts for Fee Dues, Parent-Teacher Meetings (PTM), and Vacations.
   - Pre-formatted for instant copy-pasting to WhatsApp Web/Desktop with emojis and formatting.
   - Printable official school letterhead notice.

5. **📚 Lesson Plan & Notes Planner**:
   - Day-wise curriculum breakdown (Objectives, In-class activities, and Homework tasks).
